Shadowrocket 配置导入

国内直连 · 去广告 · 其余代理 · 防 DNS / WebRTC 泄漏

第 1 步

导入配置

请在 iPhone 的 Safari 里点下面的按钮，会跳到小火箭安装并使用配置。

一键导入到 Shadowrocket

在电脑上打开的话，用 iPhone 相机扫码：

手动添加：小火箭 → 配置 → 右上角 + → 粘贴配置链接 → 下载 → 点该配置 → 使用配置。

第 2 步（只需一次）

设置 GeoIP 数据库

小火箭不支持通过配置文件或链接设置 GeoIP，需要手动粘贴一次：

  1. 小火箭 → 设置 → GeoLite2 数据库
  2. 把链接粘贴到「国家」的 URL，点 更新
  3. 打开「自动后台更新」，间隔选 7 天
第 3 步

开启自动更新并自检

  1. 设置 → 自动更新 → 配置：打开「自动后台更新」，间隔选 1 天
  2. 系统设置 → 通用 → 后台 App 刷新：给小火箭打开
  3. 小火箭 → 设置 → UDP → 启用转发：打开（WebRTC 显示节点 IP 需要它）
  4. 首页「全局路由」选配置，连接后打开 browserleaks.com/dns 和 /webrtc：DNS 不应出现中国大陆服务器；WebRTC 的 IPv4 应是节点 IP、IPv6 为 ::1 或空，都不能是你的真实 IP
